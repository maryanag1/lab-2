# Общее описание решения
 Geometric Lib — библиотека на языке Python для выполнения геометрических вычислений. Проект содержит функции, предназначенные для вычисления площади и периметра соответствующей фигуры. В рамках первой лабораторной работы в проект были добавлены функции для работы с прямоугольником и треугольником, а также была исправлена ошибка в вычислении периметра прямоугольника.
# Описание функций
## **circle.py**
**- Функция area(r): Вычисляет площадь круга по заданному радиусу.**
- Параметры:
    - r(int): радиус
- Возвращаемое значение:
    - math.pi*r*r  - площадь круга
**- Функция perimeter(r): Возвращает периметр круга с радиусом r.**
- Параметры:
    - r(int): радиус
- Возвращаемое значение:
    - 2*math.pi*r  - периметр круга
_Пример вызова:_
``` python
>>> area(2)
12.566370614359172
>>> perimeter(2)
12.566370614359172
```
## **triangle.py**
**- Функция area(a, h): Вычисляет площадь треугольника по заданным основанию и высоте.**
- Параметры:
    - a(int): сторона треугольника, к которой проведена высота
    - h(int): высота треугольника
- Возвращаемое значение:
    - a*h/2  - площадь треугольника
**- Функция perimeter(a, b, c): Возвращает периметр треугольника по заданным сторонам.**
- Параметры:
    - a(int): 1 сторона треугольника
    - b(int): 2 сторона треугольника
    - c(int): 3 сторона треугольника

- Возвращаемое значение:
    - a+b+c  - периметр треугольника
_Пример вызова:_
``` python
>>> area(4, 3)
6
>>> perimeter(3, 4, 5)
12
```

## **square.py**
**- Функция area(a): Вычисляет площадь квадрата по заданной стороне.**
- Параметры:
    - a(int): сторона квадрата
- Возвращаемое значение:
    - a*a  - площадь квадрата
**- Функция perimeter(a): Возвращает периметр квадрата по заданной стороне.**
- Параметры:
    - a(int): сторона квадрата
- Возвращаемое значение:
    - 4*a  - периметр квадрата
_Пример вызова:_
``` python
>>> area(4)
16.0
>>> perimeter(4)
16
```
## **rectangle.py**
**- Функция area(a, b): Вычисляет площадь прямоугольника по заданным длине и ширине.**
- Параметры:
    - a(int): первая сторона
    - b(int): вторая сторона
- Возвращаемое значение:
        - a*b  - площадь прямоугольника
**- Функция perimeter(a, b): Возвращает периметр прямоугольника по заданным 2 сторонам.**
- Параметры:
    - a(int): первая сторона
    - b(int): вторая сторона
- Возвращаемое значение:
    - 2*(a+b)  - периметр прямоугольника
_Пример вызова:_
``` python
>>> area(4, 5)
20.0
>>> perimeter(4, 5)
18
```
